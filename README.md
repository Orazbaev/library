# Продукт
Я создаю онлайн-библиотеку манги и книг. Люди отслеживают статус публикации произведения (Manga/Book).

# Основной элемент
Основным элементом является произведение (Manga/Book), которое содержит уникальный идентификатор, название, автора и текущий статус модерации.

# Table of Statuses

| Исходный статус | Целевой статус | Разрешен / Запрещен |
| :--- | :--- | :--- |
| DRAFT | UNDER_REVIEW | Разрешен |
| UNDER_REVIEW | PUBLISHED | Разрешен |
| DRAFT | PUBLISHED | Запрещен |
| PUBLISHED | UNDER_REVIEW | Запрещен |

# Причина запрета
1. Переход DRAFT -> PUBLISHED запрещен, так как черновик манги/книги не может попасть на сайт в обход этапа модерации и проверки (UNDER_REVIEW).
2. Переход PUBLISHED -> UNDER_REVIEW запрещен, так как уже опубликованное произведение нельзя вернуть на проверку без перевода в статус скрытого или архивного.
